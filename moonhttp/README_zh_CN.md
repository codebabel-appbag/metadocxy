# 用户手册：moonhttp (`moonhttp-v1.0.6`)

**moonhttp**（亦称 `moonhttp`）是一款使用 Lua 编写的轻量级、快速且注重视觉体验的本地 HTTP 服务器。它被设计为独立的跨平台二进制可执行文件（支持 Linux、Windows 和 macOS）。

其主要目标是通过提供丰富的命令行界面 (CLI) 体验以及关于项目文件完整性的即时反馈，来加速静态网页的本地开发过程。

---

## 1. 使用的模块与技术

为了构建和打包该独立二进制文件，仅使用了 Lua 生态系统中的必要库：

* **LuaJIT / Lua 5.1**
* **LuaSocket**
* **LuaFileSystem (`lfs`)**
* **ANSI 转义码**（用于颜色和文本格式化）
* **LuaStatic / Luamake**（用于编译和二进制文件打包）

---

## 2. 支持的本地 HTTP 服务器功能

**moonhttp** 实现了 *localhost* 开发环境所需的各项核心功能：

* **灵活的网络绑定：** 支持监听回环接口（`127.0.0.1`、`localhost`）、局域网 IP 解析以及自定义主机名。
* **自动目录解析：** 针对末尾缺少斜杠的文件夹路由（例如 `/about` -> `/about/`）执行 `301 Moved Permanently` 重定向。
* **索引页处理：** 自动查找 `index.html`、`index.htm` 或 `index.lwa` 文档。
* **MIME 类型识别：** 自动识别 `.html`、`.htm`、`.lwa`、`.css`、`.js`、`.ico` 和 `.png` 格式，默认回退为 `text/plain`。
* **开发缓存控制：** 自动发送 `Cache-Control: no-cache` 响应头，防止浏览器在编辑过程中缓存旧版本文件。
* **请求方法安全：** 严格限制请求仅使用 `GET` 和 `HEAD` 方法，拦截试图通过 `POST`、`PUT` 或 `DELETE` 修改文件的请求（返回 `405 Method Not Allowed`）。 * **端口即时释放：** 利用 `SO_REUSEADDR` 配置，防止在通过 `CTRL+C` 终止应用程序时操作系统锁定端口。
* **可选的文件列表功能：** 默认禁用目录列表功能（出于安全考虑，访问时返回 `404 Not Found`），但可根据需要启用。

---

## 3. 文件检查与 Web 应用支持

### 自动资源检查（前端资源）
在提供 HTML 或 `.lwa` 文档服务时，**http.moon** 会实时分析代码并检查 `<link>`、`<script>`、`<img>` 和 `<a href>` 标签。如果引用的文件在本地文件夹中不存在，服务器会在**终端显示可视化提示**，告知您资源缺失。

### 对 JS 框架及 Web 应用的支持

* **支持的项目类型：** 静态 HTML5/CSS3/JS 站点、着陆页（Landing Pages）、本地模板、基于 **Vanilla JS**（原生 JS）构建的应用，以及 `.lwa` 文件（视为标准 HTML 处理）。
* **JS 框架构建产物（React、Vue、Svelte、Angular）：** 在执行框架的构建命令后，**http.moon** 可无缝提供由这些工具生成的静态导出文件夹（如 `dist/` 或 `build/`）的服务。 * **局限性（不支持的功能）：**
* 无法替代 JS 框架开发过程中使用的、具备“热模块替换”（HMR）功能的开发服务器（如 Vite、Webpack、Next.js 的 DevServer）。 
* 不支持执行动态服务端代码（如 Node.js、PHP、Python 等）或连接数据库。

## 4. 版本历史

* **v1.0.0：** 初始版本，支持当前工作目录（CWD）、通过 CLI 绑定端口/主机、解析 `index.html`/`index.htm`/`index.lwa`、记录 404 错误日志以及优雅关闭服务。
* **v1.0.1：** 新增**静态依赖检查器**、ASCII 艺术风格 Logo 显示，以及利用 ANSI 颜色代码实现的终端可点击链接功能。 * **v1.0.2:** 增加了针对末尾不带斜杠（trailing slash）的文件夹/目录的路由处理，并采用 `301` HTTP 重定向。
* **v1.0.3:** 增加了针对 HTTP 方法（`GET`/`HEAD`）的安全限制、开发环境下的防缓存响应头，以及对 `--dir-list` 标志的支持。

## 5. 完整的 CLI 命令指南

执行该二进制文件的基本语法如下：

```bash
moonhttp [flags]
```

### 参数与标志

| 描述 | 默认值 |
| :--- | :--- |
|**-h:<host>**  | 设置监听的网络接口/主机地址 (127.0.0.1)|
|**-p:<port>** | 配置服务器网络端口 (7777，或针对 moon/moonip 配置文件的 8888)|
|**--dir-list** | * 当不存在索引文件（index file）时，启用文件夹文件列表显示功能。|
|**-help 或 --help**| 显示应用程序帮助信息及可用命令。|
|**-manual 或 --manual**| 显示 GitHub 上 manual.md 的链接。|
|**-v, -version 或 --version**| 显示 moonhttp 版本号。|
```
已禁用（返回 404）
实际使用示例

1. 标准执行（最基本用法）：在当前工作目录 (CWD) 启动服务器，
使用 IP 127.0.0.1 和端口 7777。Bash: ./moonhttp | Windows: moonhttp.exe
```

#### 2. 使用 'localhost' 主机快捷方式

> 将主机设置为 127.0.0.1，端口设置为 7777
```bash
./moonhttp -h:localhost
```

#### 3. 仅更改端口
> 在自定义端口 5677 启动服务器，同时保持 IP 为 127.0.0.1。
```bash
./moonhttp -p:5677
```

#### 4. 使用 'moon' 配置项
> 使用预配置的 'moon' 别名，在 IP 127.0.0.1 和端口 8888 启动服务器。

```bash
./moonhttp -h:moon
```

#### 5. 使用 'moonip' 在局域网内共享
> 自动识别本机的局域网 IP（例如 192.168.1.15）并使用端口 8888，允许同一 Wi-Fi/以太网内的其他设备访问该站点。

```bash
./moonhttp -h:moonip
```

#### 6. 指定自定义主机和端口
> 在特定的机器 IP 和您选择的端口上启动服务器。

```bash
./moonhttp -h:192.168.0.50 -p:3000
```

#### 7. 启用目录列表显示
> 如果文件夹中不包含 index.html 文档，则允许在浏览器中浏览文件结构。

```bash
./moonhttp --dir-list
```

#### 8. 高级命令（局域网 + 自定义端口 + 目录列表显示）

在机器的局域网 IP 上启动服务器，使用手动指定的端口并启用目录列表显示。 ```bash

./moonhttp -h:moonip -p:9000 --dir-list

```
